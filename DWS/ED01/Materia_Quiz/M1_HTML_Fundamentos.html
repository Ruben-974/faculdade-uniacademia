1. Estrutura e Sintaxe HTML

1.1 O que é HTML? Definição e Propósito

Definição: HTML é a abreviação das palavras HyperText Markup Language, que pode ser traduzido como Linguagem de Marcação de Hipertexto.

TermoSignificado
HyperText (Hipertexto)Texto que contém links (hiperlinks) para outros textos, permitindo navegação não-linear.
Markup (Marcação)Uso de "tags" para descrever a estrutura e o significado do conteúdo.
Language (Linguagem)Um conjunto de regras e convenções sintáticas que o navegador interpreta.

Função do HTML: Criar páginas na Internet.

Você pode criar com HTML:

  • Textos nas páginas
  • Fazer formatação (negrito, itálico, sublinhado, cores, tamanhos)
  • Criar listas (ordenadas, não ordenadas, de definição)
  • Criar tabelas
  • Criar formulários
  • Trabalhar com imagens
  • Criar links (locais, externos, e-mail)
  • Etc.
Nota importante: O HTML cria páginas estáticas, sem animação.
Tome nota: Dentro deste contexto, em um site simples, o servidor web vai retornar dentro da mensagem HTTP o código HTML para exibição da página. O computador cliente tem a responsabilidade de interpretar tais códigos e atualizar a tela.

1.2 Estrutura Básica do Arquivo HTML

<html>
  <head>
    <title>Meu site!!!</title>
  </head>

  <body>
    Texto principal aqui
  </body>
</html>
TagDescrição
<HTML> ... </HTML>Indicam respectivamente o início e o fim de um documento HTML. Todos os outros elementos devem estar entre estas marcas.
<HEAD> ... </HEAD>Delimitam a seção de cabeçalho do documento. Trata-se da primeira seção do documento.
<TITLE> ... </TITLE>Indicam o título do documento, que será exibido na barra de título do navegador. Estas marcas devem constar da seção de cabeçalho.
<BODY> ... </BODY>Representam o corpo do documento. Entre estas marcas estará contida a maior parte do conteúdo a ser exibido com textos e imagens.

Explicação detalhada: Na construção da página, basicamente, deve ser descritas as marcações de informação sobre a página dentro da tag head e o conteúdo, dentro da tag body.

1.3 Sintaxe dos Comandos HTML

ComponenteDescrição
< >Marca de abertura
</>Marca de fechamento

Definição de tag:

  • Uma tag é um rótulo (semelhante a um comando) que indica ao navegador como determinado objeto da página deve ser apresentado.
  • Todas as tags têm o mesmo formato e são indicadas por <tag>.
  • Porém a tag de fechamento possui uma "/" entre os sinais "<" e ">" (</tag>).
  • Na verdade, para definir uma característica (rótulo) na página são utilizadas duas (*) tags.

1.4 Atributos HTML

  • Muitas tags HTML possuem atributos.
  • Os atributos são propriedades das tags que definem novas características para sua ação.
  • Os atributos são colocados dentro da tag, seguidos pelo sinal "=" e, quando se tratar de mais de um atributo, devem ser separados por vírgula (na prática, por espaço).

Exemplo com a tag <font>:

<font size="7" face="Arial" color="#009900">
  Texto principal aqui
</font>
AtributoDescriçãoValores
sizeTamanho da fonte1 a 7
faceEstilo de fonte"Arial", "Times New Roman", etc.
colorCor da fonteHexadecimal ou nome

Sobre o atributo face: Podemos definir vários estilos de fontes, pois sempre que o sistema não possuir a primeira, ele utilizará a segunda, assim por diante.

Demonstração de Tamanhos de Fonte (size 1 a 7)

<font size="1" face="Arial" color="#009900">Fonte</font><BR>
<font size="2" face="Arial" color="#009900">Fonte</font><BR>
<font size="3" face="Arial" color="#009900">Fonte</font><BR>
<font size="4" face="Arial" color="#009900">Fonte</font><BR>
<font size="5" face="Arial" color="#009900">Fonte</font><BR>
<font size="6" face="Arial" color="#009900">Fonte</font><BR>
<font size="7" face="Arial" color="#009900">Fonte</font><BR>
Observação moderna: A tag <font> está obsoleta em HTML5. Use CSS para estilizar texto.

1.5 Requisitos para Começar

O que precisamos?

  1. Um editor de textos qualquer.
  2. E o browser (navegador) Mozilla.

Observações:

  • Os arquivos devem ser salvos no formato texto puro (.txt) e com extensão .htm ou .html.
  • Todos os arquivos de um projeto devem ser preferencialmente colocados dentro de uma mesma pasta (diretório).

2. Listas em HTML

O HTML oferece três tipos principais de listas: ordenadas, não ordenadas e de definição.

2.1 Listas Ordenadas <ol> (Ordered List)

Usadas quando a ordem dos itens é importante. Cada item é envolvido pela tag <li> (line item).

2.1.1 Estrutura Básica

<ol>
  <li>Primeiro item</li>
  <li>Segundo item</li>
  <li>Terceiro item</li>
</ol>

Resultado visual:

  1. Primeiro item
  2. Segundo item
  3. Terceiro item

2.1.2 Atributo type — Tipo de Ordenação

ValorDescriçãoExemplo de Saída
1Lista numérica comum (padrão)1, 2, 3, 4, 5...
ALista alfabética maiúsculaA, B, C, D, E...
aLista alfabética minúsculaa, b, c, d, e...
IAlgarismos romanos maiúsculosI, II, III, IV, V...
iAlgarismos romanos minúsculosi, ii, iii, iv, v...

2.1.3 Atributo start — Valor Inicial

Define qual será o valor do item inicial da lista.

<ol type="A" start="3">
  <li>Primeiro item</li>
  <li>Segundo item</li>
  <li>Terceiro item</li>
</ol>

Resultado visual:

  1. Primeiro item
  2. Segundo item
  3. Terceiro item
Nota importante: Quando os atributos forem suprimidos, a lista será numérica e terá início com o valor 1.

2.1.4 Exemplo Completo

<!-- Lista numérica -->
<ol>
  <li>Primeiro item</li>
  <li>Segundo item</li>
  <li>Terceiro item</li>
</ol>

<!-- Lista alfabética maiúscula começando em C -->
<ol type="A" start="3">
  <li>Primeiro item</li>
  <li>Segundo item</li>
  <li>Terceiro item</li>
</ol>

<!-- Lista em algarismos romanos começando em V -->
<ol type="I" start="5">
  <li>Primeiro item</li>
  <li>Segundo item</li>
  <li>Terceiro item</li>
</ol>

2.2 Listas Não Ordenadas <ul> (Unordered List)

Usadas quando a ordem dos itens não é importante. Cada item é envolvido pela tag <li>.

2.2.1 Estrutura Básica

<ul>
  <li>Primeiro item</li>
  <li>Segundo item</li>
  <li>Terceiro item</li>
</ul>

2.2.2 Atributo type — Tipo de Marcador

ValorDescriçãoAparência
discMarcadores redondos (padrão)●
circleMarcadores circulares (vazados)○
squareMarcadores quadrados▪
noneSem marcadores(nenhum)

2.2.3 Exemplo Completo

<ul>
  <li>Primeiro item</li>
  <li>Segundo item</li>
  <li>Terceiro item</li>
</ul>

<ul type="circle">
  <li>Primeiro item</li>
  <li>Segundo item</li>
  <li>Terceiro item</li>
</ul>

<ul type="square">
  <li>Primeiro item</li>
  <li>Segundo item</li>
  <li>Terceiro item</li>
</ul>

<ul type="none">
  <li>Primeiro item</li>
  <li>Segundo item</li>
  <li>Terceiro item</li>
</ul>

2.3 Listas Aninhadas

As listas aninhadas possuem níveis e subníveis. É uma lista dentro de outra lista.

Dica: Para evitar problemas, faça primeiro a lista principal.

2.3.1 Exemplo Completo

<ol>
  <li><strong>Primeira Lista</strong>
    <ul type="disc">
      <em>Lista não Ordenada Padrão</em>
      <li>Primeiro item</li>
      <li>Segundo item</li>
      <li>Terceiro item</li>
    </ul>
  </li>

  <li><strong>Segunda Lista</strong>
    <ul type="circle">
      <em>Lista não Ordenada Marcador Circular</em>
      <li>Primeiro item</li>
      <li>Segundo item</li>
      <li>Terceiro item</li>
    </ul>
  </li>

  <li><strong>Terceira Lista</strong>
    <ul type="square">
      <em>Lista não Ordenada Marcador Quadrado</em>
      <li>Primeiro item</li>
      <li>Segundo item</li>
      <li>Terceiro item</li>
    </ul>
  </li>
</ol>

Nota: Os itens de lista podem conter uma nova lista e outros elementos HTML, como imagens e links, etc.

2.4 Listas de Definição <dl> (Definition List)

É uma lista de termos, com uma descrição de cada termo.

TagSignificadoFunção
<dl>"definition list"Contêiner da lista de definição
<dt>"definition term"O termo a ser definido
<dd>"definition description"A descrição do termo

2.4.1 Exemplo Completo

<dl>
  <dt><strong>Café</strong></dt>
  <dd>- Macchiato</dd>
  <dd>- Cappuccino</dd>
  <dd>- Café com leite</dd>

  <dt><strong>Leite</strong></dt>
  <dd>- Leite quente</dd>
  <dd>- Leite caramelado</dd>
  <dd>- Leite com chocolate</dd>
</dl>

4. Formulários em HTML

Importante: O HTML permite a criação de formulários mas não o tratamento de dados. Para tratamento de dados é necessário outras linguagens, que criam scripts para esta manipulação.

4.1 A Tag <form> e Atributos

Tag/AtributoDescrição
<form> </form>Delimita o formulário
actionDefine o endereço (URL) do servidor e o programa que irá processar as informações do formulário
methodDefine qual será o método que o servidor vai usar para a recepção dos dados: get ou post
 
<form method="método" action="URL">

Diferença entre GET e POST

O método POST envia os dados imediatamente após o URL do servidor e o método GET anexa os dados do formulário ao endereço do servidor.

CaracterísticaGETPOST
VisibilidadeDados visíveis na URLDados ocultos no corpo da requisição
Limite de tamanhoLimitado (~2000 caracteres)Sem limite prático
SegurançaBaixaMédia
Uso típicoBuscas, filtrosLogin, cadastro

4.2 A Tag <input> e Seus Tipos

<input> </input>: especifica uma entrada de dados feita pelo usuário.

TipoUtilidade
textDefine uma área de inserção de caracteres.

checkboxEntrada de dados SIM / NÃO.
radioExibe várias opções mas só aceita uma.

emailDefine uma área de inserção de e-mail.
numberExibe valores do intervalo selecionado.
dateExibe as opções de data.
colorUsado para campo que deve conter cor.
rangeControle deslizante para valores.

4.3 Atributos da Tag <input>

4.4 Tag <select> e <option>

<select></select>: define entrada de dados em forma de lista de opções. Cada opção deve ser especificada por <option>.

  Qual seu esporte preferido?
  <select name="opcoes" multiple size=5>
    <option value="natação">Natação</option>
    <option value="futebol" selected>Futebol</option>
    <option value="basquete">Basquete</option>
  </select>
</form>

4.5 Tag <textarea>

<textarea></textarea>: Define a entrada de dados como uma área de texto de digitação livre que é dimensionada pelos atributos rows=n (número de linhas) e cols=n (número de colunas), além do atributo name=variável.

  </form>
</body>
</html>

5. Imagens em HTML

5.1 A Tag <img> e Sua Sintaxe

A tag <img> é uma tag vazia (void element), ou seja, não possui tag de fechamento.

<img src="carro.jpg" width=100>
<img src="caminho/da/imagem.jpg"
     alt="Descrição da imagem"
     width="500"
     height="300">

5.2 O Atributo src — A Fonte da Imagem

O atributo src (source) especifica o caminho para o arquivo de imagem. É o atributo mais importante e obrigatório da tag <img>.

TipoExemplo
Caminho relativo (mesma pasta)src="carro.jpg"
Caminho relativo (subpasta)src="imagens/carro.jpg"
Caminho relativo (pasta pai)src="../carro.jpg"
Caminho absoluto (URL completa)src="https://exemplo.com/imagens/carro.jpg"
Data URI (base64)src="data:image/png;base64,..."

5.3 O Atributo alt — Acessibilidade e Fallback

O atributo alt (alternative text) fornece uma descrição textual da imagem. É obrigatório para acessibilidade.

Tipo de imagemRecomendaçãoExemplo
InformativaDescreva o conteúdo e a funçãoalt="Gráfico de vendas crescendo 30% em 2026"
DecorativaUse alt="" (vazio)alt=""
Funcional (link)Descreva a açãoalt="Ir para a página inicial"
LogotipoNome da empresaalt="Logo da TechStore"

5.4 Atributos de Dimensão: width e height

<img src="carro.jpg" border=8 width=100 height=150>
SituaçãoResultado
Apenas widthA altura é ajustada proporcionalmente

8. Introdução à Internet, Redes e Boas Práticas

8.1 O que é a Internet e Sua História

Definição (do material)

  • A Internet é um conjunto de redes que estão ligados por todo o planeta.
  • Administração é feita individualmente por empresas particulares ou órgãos públicos.
  • Não existe um administrador central, o que torna a conexão de baixo custo.
  • Comunicação padronizada faz com que os computadores "conversem" entre si.
  • Comunicação chamada de protocolo ou TCP/IP (Protocolo de Controle de Transferência / Protocolo de Internet).

História da Internet no Mundo

AnoEvento
1969Ideia inicial: rede descentralizada para interligar instalações militares (ARPANET — Advanced Research Projects Agency Network).
Década de 70Várias outras redes foram sendo interligadas à ARPANET.
Década de 80São criadas redes de interconexão de instituições científicas.
1983Marco de criação da Internet, quando os militares abandonam o controle da ARPANET.

A Internet no Brasil (do material)

  • A Internet surgiu no Brasil em 1991, num primeiro momento interligando instituições acadêmicas por meio da Rede Nacional de Pesquisa.
  • A partir de 1995 começa a utilização comercial e a popularização da rede.

Principais Componentes da Internet (do material)

  • Serviços de busca de informação;
  • Correio eletrônico (e-mail);
  • Transferência de ficheiros (FTP);
  • Fóruns de discussão;
  • Conexões Remotas;
  • Vídeo Conferência; etc.

8.2 Redes de Computadores

Definição de Rede (do material)

  • Rede: É o compartilhamento de informações e serviços.
  • Um trabalho em rede é possível quando pessoas ou grupos possuem informações ou recursos que desejam compartilhar.
  • Uma Rede de computadores consiste de 2 ou mais computadores e outros dispositivos ligados entre si, compartilhando: dados, impressoras, trocando mensagens (e-mails), etc.

Classificação de Redes por Tamanho/Distância (do material)

TipoNome CompletoAbrangênciaExemplo

WANWide Area NetworkRede de longa distânciaInternet

Componentes de uma Rede (do material)

  • Cabeamento (cabos de rede)
  • Hardware (computadores, switches, roteadores)
  • Software (sistemas operacionais, protocolos)

Para uma rede operar de modo eficiente, deve haver uma correta integração entre os diversos componentes envolvidos para sua implantação.

8.5 A World Wide Web (WWW)

Definição (do material)

  • WWW: A World Wide Web — Rede de âmbito mundial ou Teia de âmbito mundial.
  • Desenvolvida no final da década de 80 numa instituição de pesquisa (CERN — Organização Europeia para a Investigação Nuclear) como forma de facilitar aos pesquisadores acesso a documentos científicos.
  • Trabalhos de pesquisadores inter-relacionados espalhados por várias máquinas diferentes.
  • Através da Web é possível, partindo de um determinado ponto, pesquisar documentos relacionados independente de sua localização física.

8.6 DNS (Domain Name System)

Definição (do material)

  • DNS: Domain Name System — Sistema de gerenciamento de nomes hierárquico e distribuído para computadores, serviços ou qualquer recurso conectado à Internet ou numa rede privada.
  • Associa várias informações atribuídas a nomes de domínios a cada entidade participante.
  • Em sua utilização mais comum, traduz nomes de domínios mais facilmente memorizáveis a endereços IP numéricos necessários à localização e identificação de serviços e dispositivos juntamente.

8.7 Tecnologia Cliente-Servidor

Definição (do material)

  • Navegadores — Para navegar pela Web é necessário um software cliente que chamamos de navegador (em inglês, Browser). Ele é responsável por solicitar documentos na Internet e interpretá-los, exibindo para o usuário.
  • Servidores Web — São programas sendo executados nas máquinas onde estão guardados os documentos.
  • Estes programas são os responsáveis por enviar os documentos para as máquinas que os solicitam. Exemplos: Apache, IIS (Microsoft).

8.8 URL (Uniform Resource Locator)

Definição (do material)

  • URL (Uniform Resource Locator) — Localizador Uniforme de Recursos.
  • Formato de endereçamento: protocolo://servidor/caminho/arquivo

Protocolo (do material)

Protocolo — Indica a forma como vai ser realizada a comunicação entre o servidor e o cliente e o tipo de serviço que será prestado. Os mais comuns são http (Hypertext Transfer Protocol — páginas comuns de hipertexto) e ftp (File Transferm Protocol — transferências de arquivos).

Servidor (do material)

Servidor — Endereço do servidor na Internet. Pode ser dado na forma nome_da_máquina domínio (como em www.nce.ufrj.br) ou através do endereço IP da máquina (como em 146.164.2.68).

URLs Relativas vs Absolutas (do material)

  • Ao fazer referências a páginas do mesmo site convém utilizar URLs relativas ao invés de absolutas. Isto facilita quando é necessário mudar todo o site de um lugar para o outro.
  • O endereço absoluto é a informação para a localização do recurso de forma independente da página atual (protocolo + domínio + caminho).
  • O endereço relativo é a informação para a localização do recurso a partir da página atual.

8.9 Home Page

Definição (do material)

  • Home Page — Documento projetado para ser a página principal de um Site.
  • Funciona como a porta de entrada e deve conter um ou mais links para as demais páginas do site ou para outros sites relacionados.
