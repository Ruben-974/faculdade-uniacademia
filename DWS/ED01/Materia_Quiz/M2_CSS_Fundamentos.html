1. Conceitos Fundamentais e Sintaxe do CSS

O CSS (Cascading Style Sheets) é uma das três tecnologias fundamentais da web moderna, ao lado do HTML e do JavaScript. Enquanto o HTML define a estrutura e o conteúdo de uma página, o CSS é responsável por toda a apresentação visual: cores, fontes, espaçamentos, layouts, animações e responsividade.

1.1 O que é CSS? Definição e Propósito

Conforme apresentado no material, o CSS é um acrônimo para Cascading Style Sheet, que em português significa Folha de Estilo em Cascata.

  • Folha de Estilo: Um documento que contém um conjunto de regras de estilo.
  • Em Cascata: Refere-se à forma como as regras são aplicadas. Múltiplas folhas de estilo podem ser aplicadas a um mesmo documento, e o navegador resolve conflitos seguindo uma ordem de prioridade.

O material didático define o CSS como um "conjunto de regras que informa a um programa, responsável pela formatação de um documento, como organizar a página, como posicionar e expor o texto". Em outras palavras, o CSS é a linguagem que dita a apresentação dos documentos web.

💡 O Princípio da Separação de Responsabilidades: O CSS surgiu para separar a estrutura (HTML) da apresentação (CSS), trazendo benefícios como manutenção facilitada, reaproveitamento, acessibilidade e performance.

1.2 A Sintaxe do CSS: A Anatomia de uma Regra

A sintaxe do CSS é simples, mas fundamental. Toda regra CSS é composta por duas partes principais: o Seletor e a Declaração.

Estrutura Visual:

Seletor { propriedade: valor }
Componente Definição Exemplo
Seletor É a tag do elemento da marcação ou uma entidade capaz de definir com precisão em qual lugar da marcação será aplicada a regra CSS. p, #titulo, .destaque
Declaração Determina os parâmetros de estilização. É o bloco de código entre chaves { }. { color: blue; font-size: 16px; }
Propriedade Define qual será a característica do elemento a ser estilizada. color, font-size, margin
Valor É a quantificação ou qualificação da propriedade. blue, 16px, 20px

Exemplo Prático de uma Regra CSS:

p {
    color: #FF0000;
    font-size: 16px;
    font-family: Arial, sans-serif;
}

Regras de Sintaxe:

  • Cada declaração termina com ponto e vírgula (;).
  • Os valores são separados da propriedade por dois pontos (:).
  • O bloco de declarações é delimitado por chaves ({ }).
  • O CSS é case-insensitive para propriedades e valores, mas é boa prática escrever tudo em minúsculas.

1.3 Seletores em Profundidade

1.3.1 Seletor de Tag (Elemento)

Aplica a regra a todos os elementos daquela tag no documento.

h1 {
    color: #00008B;
    font-size: 48px;
}
  • Vantagem: Simples e rápido para estilos globais.
  • Desvantagem: Pouco específico, pode afetar elementos indesejados.

1.3.2 Seletor de ID

Usa o atributo id do HTML, precedido pelo símbolo #. O ID é único: cada elemento pode ter apenas um ID, e cada página pode ter apenas um elemento com aquele ID.

<p id="p_2">Somente este parágrafo receberá a regra.</p>
#p_2 {
    font-family: "Trebuchet MS", Arial, sans-serif;
    font-size: 16px;
    color: #FFFFFF;
    font-weight: bold;
}
  • Vantagem: Alta especificidade, ideal para elementos únicos.
  • Desvantagem: Não reutilizável.

1.3.3 Seletor de Classe

Usa o atributo class do HTML, precedido por um ponto .. A classe não é única: pode ser usada para vários elementos, e um mesmo elemento pode ter várias classes.

<p class="p_2">Este parágrafo receberá o estilo.</p>
<p class="p_2">Este também receberá o mesmo estilo.</p>
.p_2 {
    font-family: "Trebuchet MS", Arial, sans-serif;
    font-size: 16px;
    color: #FFFFFF;
    font-weight: bold;
}
  • Vantagem: Reutilizável, flexível e modular.
  • Desvantagem: Menor especificidade que o ID.

1.3.4 Comparação: ID vs. Classe

Uso no HTML<p id="unico"><p class="repetivel">
Uso no CSS#unico { }.repetivel { }

1.4 A Natureza "Cascata" do CSS

O termo "Cascading" (Cascata) descreve como o navegador resolve conflitos quando múltiplas regras se aplicam ao mesmo elemento. A cascata segue uma ordem de prioridade:

  1. Origem da Regra: Estilos do navegador < Estilos do usuário < Estilos do autor.
  2. Especificidade: Inline (style="") > ID (#) > Classe (.) > Tag (p).
  3. Ordem de Declaração: A regra que vier por último no código vence (em caso de empate).

1.6 Exemplo Completo: HTML + CSS Externo

Arquivo index.html:

<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <title>Meu site!!!</title>
    <link rel="stylesheet" type="text/css" href="estilo.css">
</head>
<body>
    <h1>CSS - Cascading Style Sheets</h1>
    <p>Primeiro exemplo de folha de estilo.</p>
    <p id="p_2">Somente o parágrafo com ID receberá a regra.</p>
    <p class="destaque">Este parágrafo tem a classe "destaque".</p>
    <p class="destaque">Este também tem a classe "destaque".</p>
</body>
</html>

Arquivo estilo.css:

/* Estilo para a tag body */
body {
    background-color: #00008B;
    color: #FFFFFF;
    font-family: Arial, Helvetica, sans-serif;
}

/* Estilo para todas as tags h1 */
h1 {
    font-size: 48px;
    color: #E8E8E8;
    text-align: center;
}

/* Estilo para o parágrafo com ID p_2 */
#p_2 {
    font-family: "Trebuchet MS", Arial, sans-serif;
    font-size: 16px;
    color: #FFFFFF;
    font-weight: bold;
}

/* Estilo para a classe destaque */
.destaque {
    background-color: #FFFF00;
    color: #000000;
    padding: 10px;
    border: 2px solid #FF0000;
}

2. Formas de Inserção do CSS e Seletores

Uma das grandes vantagens do CSS é a flexibilidade de poder ser inserido no documento HTML de diferentes maneiras. Cada forma de inserção tem seus prós e contras, e a escolha correta impacta diretamente na manutenção, performance e escalabilidade do projeto.

2.1 Formas de Inserção do CSS

Forma Localização Abrangência Reutilização
ExternoArquivo .css separadoVárias páginasSim
IncorporadoTag <style> no <head>Apenas a página atualNão
InlineAtributo style na tag HTMLApenas o elemento atualNão

2.1.1 CSS Externo (External CSS)

O CSS Externo é a forma mais recomendada e amplamente utilizada em projetos profissionais. As regras de estilo ficam em um arquivo separado com extensão .css, e a página HTML faz um link para esse arquivo.

Arquivo index.html:

<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <title>Meu site!!!</title>
    <link rel="stylesheet" type="text/css" href="estilo.css">
</head>
<body>
    <h1>CSS - Cascading Style Sheets</h1>
    <p>Primeiro exemplo de folha de estilo.</p>
</body>
</html>

Arquivo estilo.css:

body {
    background-color: #00008B;
    color: #FFFFFF;
    font-family: Arial, Helvetica, sans-serif;
}

h1 {
    font-size: 48px;
    color: #E8E8E8;
}

Análise da tag <link>:

AtributoValorFunção
rel"stylesheet"Define a relação entre o documento HTML e o arquivo linkado.
type"text/css"Especifica o tipo MIME do arquivo (opcional em HTML5).
href"estilo.css"O caminho para o arquivo CSS.
✅ Vantagens do CSS Externo:
  • Separação total de responsabilidades.
  • Reutilização em todas as páginas do site.
  • Manutenção facilitada (alterar um arquivo afeta todo o site).
  • Cache do navegador (carregamento mais rápido).
  • Código HTML mais limpo.
  • O código CSS fica "escondido" do usuário.

2.1.2 CSS Incorporado (Internal CSS)

O CSS Incorporado é definido dentro da tag <style>, geralmente no <head> do documento HTML. As regras afetam somente a página atual.

<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <title>CSS</title>
    <style type="text/css">
        body {
            background-color: #FFFF00;
        }
        h1 {
            color: #00008B;
            font-size: 32px;
        }
    </style>
</head>
<body>
    <h1>Exemplo de CSS Incorporado</h1>
</body>
</html>
💡 Quando usar CSS Incorporado:
  • Páginas únicas (ex: landing pages) com estilos muito específicos.
  • Prototipagem rápida.
  • Testes e experimentos.

2.1.3 CSS Inline (Inline CSS)

O CSS Inline é aplicado diretamente no atributo style de uma tag HTML. As regras afetam somente aquele elemento específico.

<p style="color: red; font-size: 20px; font-weight: bold;">
    Este parágrafo tem estilo inline.
</p>

<h1 style="background-color: #00008B; color: #FFFFFF; text-align: center;">
    Título com estilo inline
</h1>
⚠️ Desvantagens do CSS Inline:
  • Impossível de manter em projetos grandes.
  • Mistura total de responsabilidades.
  • Não reutilizável.
  • Não suporta pseudo-classes (:hover, :focus).

2.1.4 Comparação e Ordem de Prioridade

Quando múltiplas formas de CSS se aplicam ao mesmo elemento, a cascata resolve o conflito seguindo esta ordem de prioridade (da menor para a maior):

  1. CSS do Navegador (User Agent): Estilos padrão do navegador.
  2. CSS Externo: Regras do arquivo .css.
  3. CSS Incorporado: Regras dentro de <style>.
  4. CSS Inline: Regras no atributo style.
  5. !important: Sobrescreve tudo.

2.2 Seletores e Atributos HTML

2.2.1 Atributo id

O atributo id é usado para identificar um único elemento na página. Regras CSS que usam ID são precedidas por #.

  • Cada elemento pode ter apenas um id.
  • Cada página pode ter apenas um elemento com aquele id.
  • O id deve ser único em todo o documento.

2.2.2 Atributo class

O atributo class é usado para agrupar múltiplos elementos que compartilham o mesmo estilo. Regras CSS que usam classe são precedidas por ..

  • Um elemento pode ter múltiplas classes: <p class="destaque grande">.
  • Vários elementos podem ter a mesma classe.
  • Uma classe pode ser usada em diferentes tipos de elementos.

3. Box Model (Modelo de Caixa)

O Box Model é um dos conceitos mais fundamentais do CSS. Todo elemento HTML renderizado em uma página é tratado pelo navegador como uma caixa retangular, e é o Box Model que define como essa caixa é construída.

📌 Definição do Material: "Os elementos HTML geram uma caixa em sua volta, esta caixa é que chamamos de BOX MODEL. Esta caixa é formada por 3 propriedades do elemento: Margin, Padding e Border."

3.1 Representação Visual do Box Model

🔍 Diagrama do Box Model
Element Content

Quando o navegador renderiza um elemento HTML, ele cria uma caixa retangular composta por quatro áreas concêntricas, de dentro para fora:

  1. Content (Conteúdo): O conteúdo propriamente dito (texto, imagem, vídeo, etc.). Suas dimensões são definidas por width e height.
  2. Padding (Preenchimento): O espaço interno entre o conteúdo e a borda. É transparente, mas "empurra" a borda para longe do conteúdo.
  3. Border (Borda): Uma linha que circunda o padding e o conteúdo.
  4. Margin (Margem): O espaço externo entre a borda e os elementos vizinhos. É sempre transparente.

3.2 Margin (Margem)

A margin é o espaço externo ao elemento. É a distância entre a borda de um elemento e os elementos ao seu redor (ou a borda do documento HTML).

3.2.1 Sub-propriedades de Margin

PropriedadeDescriçãoExemplo
margin-topMargem superiormargin-top: 20px;
margin-rightMargem direitamargin-right: 10px;
margin-bottomMargem inferiormargin-bottom: 15px;
margin-leftMargem esquerdamargin-left: 30px;

3.2.2 Shorthand margin

SintaxeComportamento

margin: 10px 20px;10px em cima/baixo, 20px à esquerda/direita.
margin: 10px 20px 30px;10px em cima, 20px lados, 30px embaixo.
margin: 10px 20px 30px 40px;TRBL (sentido horário, começando do topo).

3.2.3 Colapso de Margens (Margin Collapsing)

Quando duas margens verticais se encontram (margem inferior de um elemento + margem superior do próximo), elas não somam — a maior delas prevalece.

.elemento1 { margin-bottom: 30px; }
.elemento2 { margin-top: 20px; }

A distância entre os dois elementos será 30px (o maior valor), e não 50px.

3.3 Padding (Preenchimento)

O padding é o espaço interno entre o conteúdo e a borda. É sempre transparente e usa a cor de fundo do elemento.

6. Propriedade Links e Pseudo-classes

Os links são a espinha dorsal da web. No CSS, os links podem receber todas as personalizações já vistas, mas também possuem estados que podem ser estilizados individualmente através de pseudo-classes.

6.1 O que são Pseudo-classes?

Uma pseudo-classe é uma palavra-chave adicionada a um seletor que especifica um estado especial do elemento selecionado.

seletor:pseudo-classe {
    propriedade: valor;
}

6.2 As Quatro Pseudo-classes de Links

Pseudo-classeDefinição (do Material)Quando se aplica
:linkUsada para links não visitados.Estado padrão de um link que o usuário ainda não clicou.
:visitedUsada para links visitados.Após o usuário ter clicado no link.
:activeUsada para links ativos.No momento exato do clique.
:hoverUsada quando o cursor do mouse está sobre o link.Enquanto o mouse permanece sobre o link.

6.3 A Ordem Correta: LVHA

📌 Ordem correta (LVHA):
  1. L — :link
  2. V — :visited
  3. H — :hover
  4. A — :active
🎨 Demonstração de Links com Pseudo-classes

Link não visitado (vermelho) | Passe o mouse (verde) | Clique (azul)

6.4 Exemplo Completo (LVHA)

/* Estado padrão (todos os links) */
a {
    font-family: Arial, Helvetica, sans-serif;
    font-size: 16px;
    text-decoration: underline;
    font-weight: bold;
    transition: color 0.3s ease;
}

/* 1. Links não visitados */
a:link { color: #FF0000; }

/* 2. Links visitados */
a:visited { color: #800080; }

/* 3. Mouse sobre o link */
a:hover { color: #00FF00; text-decoration: none; }

/* 4. Link sendo clicado */
a:active { color: #0000FF; }

7. Cores no CSS

As cores são um dos elementos mais poderosos e expressivos do design web. O CSS oferece múltiplos sistemas para definir cores, cada um com suas particularidades, vantagens e casos de uso ideais.

7.1 A Importância das Cores no Design Web

PapelDescriçãoExemplo
ComunicaçãoTransmitem significado e emoção.Vermelho = perigo, Verde = sucesso.
HierarquiaGuiam a atenção para elementos importantes.Botão primário azul, secundário cinza.
IdentidadeDefinem a marca e criam reconhecimento.Azul do Facebook, Vermelho do YouTube.
AcessibilidadeGarantem legibilidade e inclusão.Contraste texto/fundo adequado.
EstéticaCriam harmonia visual e apelo estético.Paletas complementares e análogas.
FeedbackIndicam estados e interações.Verde = válido, Vermelho = erro.

7.2 Nomes de Cores (Named Colors)

O CSS oferece 140+ nomes de cores predefinidos, que podem ser usados diretamente pelo nome.

7.4 RGB (rgb())

O sistema RGB (Red, Green, Blue) representa cores através de três canais, cada um variando de 0 a 255.

seletor {
    color: rgb(255, 0, 0);        /* Vermelho puro */
    background-color: rgb(0, 0, 255); /* Azul puro */
}

7.5 RGBA (rgba()) — RGB com Transparência

O RGBA estende o RGB adicionando um canal alfa que controla a opacidade da cor.

seletor {
    color: rgba(255, 0, 0, 0.5);  /* Vermelho com 50% de opacidade */
}

7.13 Boas Práticas com Cores

  1. Defina uma paleta limitada: 3-5 cores principais + neutras.
  2. Use variáveis CSS: Centralize as cores em :root.
  3. Garanta contraste: Mínimo 4.5:1 para texto normal.
  4. Não dependa apenas da cor: Use ícones, texto e padrões.
  5. Considere o daltonismo: Teste com simuladores.
  6. Prefira HSL para variações: Ajustar a luminosidade é intuitivo.
  7. Use RGBA/HSLA para transparências.
  8. Considere o modo escuro: Use prefers-color-scheme.

8.4 Performance e Otimização

8.4.1 Minificação

/* Antes */
.botao {
    background-color: #3498DB;
    color: #FFFFFF;
    padding: 10px 20px;
}

/* Depois (minificado) */
.botao{background-color:#3498DB;color:#FFF;padding:10px 20px}

8.4.2 Evite @import

@import no CSS bloqueia a renderização. Prefira múltiplas tags <link> no HTML ou concatenação no build.

8.4.3 Evite Animações em Propriedades Caras

Propriedades como width, height, margin e padding causam reflow. Prefira transform e opacity, que são aceleradas pela GPU.

/* Ruim */
.botao:hover {
    width: 120px; /* Causa reflow */
    height: 50px;
}

/* Bom */
.botao:hover {
    transform: scale(1.1); /* Acelerado pela GPU */
}
