1. Sistema de Grid e Layout: Os Fundamentos Conceituais

O sistema de grid do Bootstrap 3 é a espinha dorsal de qualquer layout responsivo construído com o framework. Para dominá-lo, é essencial compreender os conceitos de Box Model, a filosofia Mobile First, a estrutura de 12 colunas, os breakpoints de responsividade e a relação com o Flexbox.

1.1 Box Model: A Base de Tudo

O Box Model (Modelo de Caixa) é um conceito fundamental do CSS que define como cada elemento HTML é renderizado na página. Cada elemento é tratado como uma caixa retangular composta por quatro áreas concêntricas, de dentro para fora:

  1. Conteúdo (Content): A área onde o texto e as imagens são exibidos. Suas dimensões são controladas pelas propriedades width e height.
  2. Preenchimento (Padding): O espaço transparente entre o conteúdo e a borda. O padding "empurra" a borda para longe do conteúdo.
  3. Borda (Border): Uma linha que circunda o padding e o conteúdo.
  4. Margem (Margin): O espaço transparente fora da borda, que separa o elemento de outros elementos na página.
🔑 A Decisão Crucial do Bootstrap 3: O framework aplica globalmente a regra box-sizing: border-box a todos os elementos. Isso significa que as propriedades width e height incluem o padding e a borda, mas não a margem. Essa escolha simplifica drasticamente o cálculo de layouts.

Exemplo Prático: Sem border-box, uma div com width: 100px, padding: 10px e border: 5px ocuparia um total de 130px de largura (100 + 10 + 10 + 5 + 5). Com border-box, ela ocupa exatamente 100px, e o conteúdo interno é comprimido para caber.

1.2 A Filosofia Mobile First

O Bootstrap 3 foi projetado com a abordagem Mobile First (Primeiro o Móvel). Isso significa que os estilos padrão do framework são pensados, primeiramente, para telas pequenas (como as de smartphones). O layout, então, "cresce" e se adapta para telas maiores através de media queries.

💡 Implicação Prática: Se você usar apenas a classe col-xs-6 (para telas muito pequenas), essa configuração de largura será herdada por telas maiores, a menos que você especifique uma classe de breakpoint superior (como col-md-4) para sobrescrevê-la. Isso garante que a experiência em dispositivos móveis seja a mais simples e funcional possível.

1.3 Estrutura do Grid: Containers, Rows e Columns

A estrutura hierárquica do grid do Bootstrap 3 é obrigatória e segue a ordem: .container > .row > .col-*.

1.3.1 .container (ou .container-fluid)

É o elemento mais externo do grid. Ele cria um contêiner centralizado na página, com uma largura máxima predefinida que varia conforme o breakpoint (ex: 750px, 970px, 1170px). A classe .container-fluid cria um contêiner que ocupa 100% da largura da viewport, sem limites laterais.

1.3.2 .row (Linha)

A classe .row cria uma linha horizontal que serve como um wrapper para as colunas. Sua principal função é limpar os floats (clearfix) das colunas filhas e aplicar margens negativas (geralmente de -15px em cada lado) para compensar o padding (gutter) de 15px que cada coluna possui. Isso garante que o espaçamento entre as colunas seja uniforme e que a linha como um todo não transborde do contêiner.

⚠️ Regra de Ouro: Apenas elementos com classes de coluna (.col-*) podem ser filhos diretos de um .row.

1.3.3 .col-* (Colunas)

As colunas são os blocos de construção do layout. O sistema é baseado em 12 colunas. Você cria colunas combinando a classe de breakpoint (ex: col-md) com o número de colunas que o elemento deve ocupar (de 1 a 12). Por exemplo, col-md-4 ocupa 4 das 12 colunas disponíveis, ou seja, um terço da largura.

1.4 Breakpoints e Responsividade

O Bootstrap 3 define quatro breakpoints (pontos de interrupção) principais, cada um com um conjunto de classes de coluna:

Classe Tipo de Dispositivo Largura da Viewport Comportamento
.col-xs-* Telefones < 768px As colunas são fluidas e empilham-se verticalmente (cada uma ocupa 100% da largura).
.col-sm-* Tablets ≥ 768px O layout começa a se tornar horizontal. As colunas se alinham lado a lado.
.col-md-* Desktops ≥ 992px Layout horizontal completo, com as larguras definidas pelo desenvolvedor.
.col-lg-* Desktops de alta resolução ≥ 1200px Similar ao md, mas para telas ainda maiores.

Combinação de Classes: Você pode (e deve) combinar múltiplas classes de coluna em um mesmo elemento para definir comportamentos diferentes em cada breakpoint. Por exemplo: <div class="col-xs-12 col-sm-6 col-md-4">. Neste caso, o elemento ocupará a largura total em celulares, metade da largura em tablets e um terço em desktops.

Exemplo de Código Prático (Três Colunas Iguais):

<div class="container">
  <div class="row">
    <div class="col-md-4">
      <h2>Coluna 1</h2>
      <p>Conteúdo da primeira coluna.</p>
    </div>
    <div class="col-md-4">
      <h2>Coluna 2</h2>
      <p>Conteúdo da segunda coluna.</p>
    </div>
    <div class="col-md-4">
      <h2>Coluna 3</h2>
      <p>Conteúdo da terceira coluna.</p>
    </div>
  </div>
</div>

Neste exemplo, em telas de desktop (≥992px), as três colunas aparecerão lado a lado, cada uma ocupando 1/3 da largura. Em telas menores, elas se empilharão verticalmente.

Exemplo de Código Prático (Colunas Responsivas):

<div class="container">
  <div class="row">
    <div class="col-xs-12 col-sm-6 col-md-4">
      <p>Coluna A</p>
    </div>
    <div class="col-xs-12 col-sm-6 col-md-4">
      <p>Coluna B</p>
    </div>
    <div class="col-xs-12 col-sm-12 col-md-4">
      <p>Coluna C</p>
    </div>
  </div>
</div>

Comportamento:

  • Celular (<768px): Todas as colunas ocupam 100% da largura (empilhadas).
  • Tablet (≥768px): Colunas A e B ficam lado a lado (50% cada), e a Coluna C fica abaixo, ocupando 100%.
  • Desktop (≥992px): As três colunas ficam lado a lado (33,3% cada).

1.5 Flexbox vs. Box Model no Contexto do Bootstrap 3

É crucial entender a distinção entre esses dois conceitos, pois eles não são a mesma coisa e, no Bootstrap 3, não devem ser misturados no sistema de grid.

  • Box Model: É a estrutura de um elemento individual. O sistema de grid do Bootstrap 3 é construído sobre o Box Model e utiliza a propriedade CSS float: left para posicionar as colunas lado a lado.
  • Flexbox: É um modelo de layout do CSS3 para distribuir espaço e alinhar itens em um contêiner. É um sistema unidimensional (linha ou coluna).
⚠️ Atenção — Armadilha Comum: Aplicar display: flex a uma .row do Bootstrap 3 quebrará o layout. Isso acontece porque o Flexbox assume o controle do dimensionamento dos elementos filhos. As propriedades width definidas pelas classes col-* (que dependem do modelo de float) são ignoradas, e as colunas passam a se dimensionar com base no conteúdo, e não na proporção de 12 colunas.
📌 Nota sobre Versões: O Flexbox tornou-se o sistema de grid nativo apenas no Bootstrap 4. No Bootstrap 3, o grid é baseado em floats. Portanto, para seguir fielmente o material apresentado, utilize as classes de grid como col-md-* e evite aplicar display: flex diretamente às .row.

2. Componentes de Formulário

Os formulários são a principal forma de interação entre o usuário e uma aplicação web. No Bootstrap 3, os formulários recebem um tratamento especial para garantir que sejam visualmente agradáveis, acessíveis e, acima de tudo, responsivos. O framework não apenas estiliza os campos, mas também fornece uma estrutura de grid para alinhá-los, além de classes para estados de validação e feedback visual.

2.1 A Estrutura Básica de um Formulário

Antes de mergulhar nos componentes individuais, é preciso entender a estrutura padrão que o Bootstrap 3 exige para formulários verticais (o padrão).

  • <form>: O contêiner principal. Embora o Bootstrap 3 não exija a classe .form (como em versões anteriores), é uma boa prática usar <form role="form"> para acessibilidade.
  • .form-group: Esta é a classe mais importante. Ela envolve cada par de label + input. Sua função é aplicar uma margem inferior (geralmente 15px) para separar verticalmente os grupos de campos, garantindo um espaçamento consistente e limpo.
  • .form-control: A classe mágica para inputs. Ela aplica width: 100%, altura padronizada, padding interno, bordas arredondadas, cor de fundo e um efeito de foco (box-shadow azul). Ela é aplicada a <input>, <textarea> e <select>.

Exemplo Básico (Vertical):

<form role="form">
  <div class="form-group">
    <label for="email">Email:</label>
    <input type="email" class="form-control" id="email" placeholder="Digite seu email">
  </div>
  <div class="form-group">
    <label for="senha">Senha:</label>
    <input type="password" class="form-control" id="senha" placeholder="Digite sua senha">
  </div>
</form>

2.2 Labels + Textfields (Rótulos e Campos de Texto)

O material apresenta uma abordagem específica para alinhar rótulos e campos de texto usando o Sistema de Grid. Em vez de usar o formulário vertical padrão, o exemplo utiliza uma estrutura horizontal (row + col-md-*).

  • Label: A tag <label> é usada para descrever o campo. O atributo for deve corresponder ao id do input para que, ao clicar no rótulo, o campo seja focado (acessibilidade).
  • Textfield: O <input type="text"> com a classe .form-control ocupa 100% da largura da coluna onde está inserido.

Análise do Código do Material (Email e Nome):

<div class="row">
  <div class="col-md-1">
    <label><h4>Email: </h4></label>
  </div>
  <div class="col-md-5">
    <div class="input-group">
      <span class="input-group-addon" id="basic-addon1">@</span>
      <input type="text" class="form-control" placeholder="Informe seu email" aria-describedby="basic-addon1">
    </div>
  </div>
</div>
  • Observação: O uso de <h4> dentro do <label> é uma prática de estilização para aumentar a fonte do rótulo, embora não seja estritamente semântico (o ideal seria usar CSS para isso).
  • Grid: A coluna do rótulo ocupa 1 parte (col-md-1) e a do campo ocupa 5 partes (col-md-5), deixando 6 partes vazias à direita.
  • Acessibilidade: O atributo aria-describedby="basic-addon1" conecta o input ao span que contém o @, garantindo que leitores de tela entendam o contexto.

2.3 Input Groups (Grupos de Input)

O Input Group é um componente poderoso para estender campos de formulário. Ele permite adicionar texto, ícones ou botões antes, depois ou em ambos os lados de um input.

  • .input-group: O contêiner que agrupa o input e os complementos.
  • .input-group-addon: Usado para adicionar texto ou ícones (como o @ no exemplo do material).
  • .input-group-btn: Usado para adicionar botões ao grupo.

Exemplo Prático (com addon e botão):

<div class="input-group">
  <span class="input-group-addon">R$</span>
  <input type="text" class="form-control" placeholder="Valor do produto">
  <span class="input-group-btn">
    <button class="btn btn-default" type="button">Calcular</button>
  </span>
</div>

2.4 Dropdown (Select / Menu Suspenso)

O elemento <select> é estilizado com a classe .form-control. Ele herda a largura de 100% do seu contêiner pai (geralmente uma coluna do grid).

  • <option>: Define cada item da lista.
  • value: É o valor que será enviado ao servidor.
  • selected: Define qual opção aparece por padrão.

Análise do Código do Material (Estado):

<div class="row">
  <div class="col-md-1">
    <label><h4>Estado: </h4></label>
  </div>
  <div class="col-md-2">
    <select class="form-control" name="comboestado">
      <option value="null"> </option>
      <option value="MG">MG</option>
      <option value="MG">SP</option> <!-- ERRO NO MATERIAL: value deveria ser "SP" -->
      <option value="RJ">RJ</option>
    </select>
  </div>
</div>
⚠️ Ponto de Atenção (Erro no Material): No código apresentado no slide, a opção "SP" está com value="MG". Isso é um erro grave de programação, pois, ao enviar o formulário, o servidor receberia "MG" mesmo que o usuário tivesse selecionado "SP". É um excelente exemplo prático de por que devemos sempre revisar o código.

Boas Práticas: O <option value="null"> </option> cria uma opção vazia inicial, forçando o usuário a fazer uma escolha ativa.

2.5 Radio Buttons (Botões de Rádio)

Os botões de rádio permitem que o usuário selecione apenas uma opção entre várias. No Bootstrap 3, a estrutura recomendada é envolver cada input em uma <label> e agrupar tudo em uma div com a classe .radio.

  • type="radio": Define o tipo do input.
  • name: Crucial. Todos os botões de rádio do mesmo grupo DEVEM ter o mesmo atributo name. Isso força a exclusividade da seleção.
  • value: O valor a ser enviado.
  • .radio: Aplica espaçamento e alinhamento adequados.

Análise do Código do Material (Sexo):

<div class="row">
  <div class="col-md-1">
    <label><h4>Sexo: </h4></label>
  </div>
  <div class="col-md-3">
    <div class="radio">
      <label>
        <input type="radio" name="optradio" value="masculino"> Masculino
      </label>
    </div>
    <div class="radio">
      <label>
        <input type="radio" name="optradio" value="feminino"> Feminino
      </label>
    </div>
  </div>
</div>

Observação: Para colocar os botões de rádio na mesma linha horizontal, o Bootstrap 3 oferece a classe .radio-inline aplicada diretamente ao <label>, em vez de usar .radio em uma div separada.

2.6 Checkboxes (Caixas de Seleção)

Diferente dos botões de rádio, os checkboxes permitem que o usuário selecione múltiplas opções. A estrutura é semelhante à dos radios, mas usando a classe .checkbox.

  • type="checkbox": Define o tipo do input.
  • name: Se for um array de valores (ex: name="optcheck[]"), o servidor receberá uma lista. Se for o mesmo nome sem colchetes, apenas o último valor será enviado.
  • .checkbox: Aplica o estilo e o espaçamento.

Análise do Código do Material (Esportes):

<div class="row">
  <div class="col-md-1">
    <label><h4>Esportes: </h4></label>
  </div>
  <div class="col-md-3">
    <div class="checkbox">
      <label>
        <input type="checkbox" name="optcheck" value="futebol"> Futebol
      </label>
    </div>
    <div class="checkbox">
      <label>
        <input type="checkbox" name="optcheck" value="volei"> Volei
      </label>
    </div>
  </div>
</div>

2.7 Button (Botões)

O Botão é o elemento que dispara a ação do formulário (geralmente um submit). O Bootstrap 3 oferece uma vasta gama de classes para estilizá-lo.

  • .btn: Classe base obrigatória. Remove o estilo padrão do navegador e aplica padding, borda e transições.
  • .btn-default: Estilo padrão (cinza claro).
  • .btn-primary: Azul escuro (ação principal).
  • .btn-success: Verde (sucesso).
  • .btn-danger: Vermelho (perigo/ação destrutiva).
  • .btn-warning: Amarelo (aviso).
  • .btn-info: Azul claro (informação).
  • .btn-link: Aparência de link.
  • Tamanhos: .btn-lg, .btn-sm, .btn-xs.
  • .btn-block: Ocupa 100% da largura do contêiner.

Análise do Código do Material (Salvar):

<div class="row">
  <div class="col-md-3">
    <button type="submit" class="btn btn-default">Salvar</button>
  </div>
</div>

Observação: O botão está dentro de uma coluna col-md-3. Isso significa que o botão ocupará a largura do seu conteúdo (não 100% da coluna, a menos que use .btn-block). O alinhamento à esquerda é o padrão.

2.8 Estados de Validação (Recurso Adicional Importante)

Embora não explicitamente mostrado nos slides, é fundamental citar que o Bootstrap 3 oferece classes para indicar o estado de validação de um campo, o que melhora a experiência do usuário:

  • .has-success: Borda e texto verdes (campo válido).
  • .has-warning: Borda e texto amarelos (atenção).
  • .has-error: Borda e texto vermelhos (erro).
  • .has-feedback: Adiciona um ícone de feedback (ex: check ou X) dentro do campo.

Exemplo Prático:

<div class="form-group has-success has-feedback">
  <label class="control-label" for="inputSuccess">Input com sucesso</label>
  <input type="text" class="form-control" id="inputSuccess">
  <span class="glyphicon glyphicon-ok form-control-feedback"></span>
</div>

2.9 Formulários Horizontais e Inline

O material apresenta uma abordagem "híbrida", usando o grid para alinhar labels e inputs. No entanto, o Bootstrap 3 possui classes específicas para isso:

  • .form-horizontal: Aplicada à tag <form>. Transforma os .form-group em .row e permite o uso de classes de grid (col-sm-*) para alinhar labels e inputs horizontalmente de forma nativa. Requer a classe .control-label nos labels.
  • .form-inline: Aplicada à tag <form>. Faz com que os campos fiquem na mesma linha, ideal para filtros e barras de busca. Requer largura automática (width: auto) nos inputs.

2.10 Acessibilidade (A11y) em Formulários

O material demonstra boas práticas de acessibilidade que merecem destaque:

  • aria-describedby: Usado no exemplo do email para conectar o input ao texto de ajuda (@). Isso permite que leitores de tela leiam "Arroba, informe seu email".
  • placeholder: Fornece uma dica visual, mas nunca deve substituir o <label>. O label é essencial para usuários de leitores de tela.
  • <label for="...">: A amarração correta entre label e input é vital para a navegação por teclado e leitores de tela.

Resumo dos Componentes de Formulário no Bootstrap 3

Componente Classe Principal Função
Grupo de Campo .form-group Espaçamento vertical entre campos.
Input de Texto .form-control Estilização padrão de inputs, selects e textareas.
Input Group .input-group Adicionar ícones, textos ou botões ao lado do input.
Addon .input-group-addon Texto/ícone dentro do input group.
Radio .radio ou .radio-inline Botões de seleção única.
Checkbox .checkbox ou .checkbox-inline Caixas de seleção múltipla.
Botão .btn + .btn-* Ação do formulário.
Validação .has-success, .has-error Feedback visual de erro/sucesso.

3. Componentes de Navegação e Conteúdo

O Bootstrap 3 oferece um conjunto de componentes prontos para estruturar a navegação e a apresentação de conteúdo. Eles garantem consistência visual e funcional, além de serem totalmente responsivos.

3.1 Breadcrumbs (Rastro de Navegação)

O Breadcrumb (ou "rastro de navegação") é um componente que indica a localização da página atual dentro da hierarquia do site. Ele ajuda o usuário a entender onde está e a navegar para níveis superiores.

3.1.1 Estrutura e Classes

O breadcrumb é construído com uma lista ordenada (<ol>) que recebe a classe .breadcrumb. Cada item da lista (<li>) representa um nível da hierarquia:

  • Itens intermediários: Contêm um link (<a>) para o nível correspondente.
  • Item ativo (página atual): Recebe a classe .active e não deve conter link (já que o usuário já está nessa página). O Bootstrap 3 estiliza o .active com uma cor de texto mais escura e sem sublinhado.

3.1.2 Exemplo Prático:

<ol class="breadcrumb">
  <li><a href="welcome.php">Página Inicial</a></li>
  <li class="active">Cadastro</li>
</ol>
  • Acessibilidade: O ideal é envolver o breadcrumb em uma tag <nav> com aria-label="breadcrumb" para que leitores de tela identifiquem a região de navegação.
  • Separadores: O Bootstrap 3 adiciona automaticamente o separador / (barra) entre os itens via CSS, usando o seletor :before com a propriedade content.

3.2 Painéis (Panels)

Os Painéis são contêineres versáteis para agrupar conteúdo em uma caixa com borda e padding. Eles são úteis para destacar informações, criar widgets ou organizar seções de uma página.

3.2.1 Estrutura do Painel

Um painel é composto por um contêiner principal e, opcionalmente, por seções de cabeçalho e rodapé:

  • .panel: Classe base obrigatória. Aplica a borda e o espaçamento externo.
  • .panel-default: Define a cor padrão do painel (cinza claro).
  • .panel-heading: Cria uma seção de cabeçalho com fundo diferenciado. Pode conter um título com a classe .panel-title (para estilização pré-definida).
  • .panel-body: A área principal de conteúdo, com padding ao redor.
  • .panel-footer: Cria um rodapé com fundo acinzentado, ideal para botões ou texto secundário.

3.2.2 Variações de Contexto

Assim como os botões, os painéis possuem variações de cor para indicar significado:

Classe Cor Uso
.panel-primary Azul Ação principal
.panel-success Verde Sucesso
.panel-info Azul claro Informação
.panel-warning Amarelo Aviso
.panel-danger Vermelho Perigo

3.2.3 Exemplo Prático:

<div class="panel panel-default">
  <div class="panel-heading">
    <h3 class="panel-title">Título do Painel</h3>
  </div>
  <div class="panel-body">
    Componentes aqui...
  </div>
  <div class="panel-footer">
    <button class="btn btn-default">Ação</button>
  </div>
</div>

3.3 Tabelas (Tables)

As tabelas do Bootstrap 3 são estilizadas com a classe .table. O framework oferece variações para melhorar a legibilidade e a usabilidade.

3.3.1 Classes Principais

  • .table: Classe base. Aplica padding, alinhamento e bordas sutis.
  • .table-striped: Adiciona listras zebradas (alternância de cores entre linhas) para facilitar a leitura de muitas linhas de dados.
  • .table-bordered: Adiciona bordas em todas as células.
  • .table-hover: Ativa um efeito de destaque ao passar o mouse sobre uma linha.
  • .table-responsive: Torna a tabela responsiva. Quando aplicada a um contêiner pai (<div>), a tabela exibirá uma barra de rolagem horizontal em telas pequenas (<768px), evitando que o layout quebre.

3.3.2 Linhas com Contexto

O Bootstrap 3 permite colorir linhas inteiras com base em um estado, usando classes aplicadas à tag <tr>:

Classe Cor Uso
.success Verde Sucesso
.info Azul Informação
.warning Amarelo Aviso
.danger Vermelho Perigo
.active Cinza Linha ativa

3.3.3 Exemplo Prático (Lista de Cadastrados):

<div class="table-responsive">
  <table class="table table-striped table-hover">
    <thead>
      <tr>
        <th>ID</th>
        <th>Nome</th>
        <th>CPF</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>1</td>
        <td>João</td>
        <td>000.000.000-00</td>
      </tr>
    </tbody>
  </table>
</div>

3.4 Glyphicons (Ícones)

O Glyphicon é uma biblioteca de ícones em fonte incluída no Bootstrap 3. Por serem fontes, os ícones podem ser redimensionados e coloridos via CSS, sem perda de qualidade.

3.4.1 Como Usar

Para usar um Glyphicon, é necessário adicionar duas classes a um elemento <span>:

  1. .glyphicon: Classe base (define a família de fontes, posicionamento, etc.).
  2. .glyphicon-*: Classe específica do ícone (ex: glyphicon-search, glyphicon-user, etc.).

Regras importantes:

  • O <span> deve estar vazio (sem texto ou elementos filhos).
  • O ícone deve ser usado em um <span> aninhado, não diretamente em outros componentes.

3.4.2 Exemplos Práticos:

Ícone de busca em um botão:

<button class="btn btn-default">
  <span class="glyphicon glyphicon-search" aria-hidden="true"></span> Buscar
</button>

Ícone de usuário ao lado de um texto:

<p>
  <span class="glyphicon glyphicon-user" aria-hidden="true"></span> João
</p>

Acessibilidade: O atributo aria-hidden="true" é recomendado para ícones puramente decorativos, evitando que leitores de tela os anunciem de forma confusa. Se o ícone for o único conteúdo de um botão (sem texto), deve-se usar aria-label para descrever sua função.

4. Estrutura Base e Recursos Técnicos

Um projeto Bootstrap 3 começa com uma estrutura HTML5 bem definida e um conjunto de arquivos essenciais. Entender essa base é fundamental para que o framework funcione corretamente, especialmente a responsividade e os componentes interativos.

4.1 O Template Básico (Basic Template)

O Bootstrap 3 exige uma estrutura HTML5 específica. O template mínimo inclui:

  • <!DOCTYPE html>: Declara o documento como HTML5. É obrigatório para que o Bootstrap aplique seus estilos corretamente.
  • <html lang="en">: Define o idioma da página (pode ser alterado para pt-br).
  • <head>: Contém os metadados e links para os arquivos CSS.
  • <body>: Contém o conteúdo visível da página.

4.1.1 Meta Tags Obrigatórias

As três meta tags a seguir devem vir primeiro no <head>, antes de qualquer outro conteúdo:

  1. <meta charset="utf-8">: Define a codificação de caracteres como UTF-8, garantindo que acentos e caracteres especiais sejam exibidos corretamente.
  2. <meta http-equiv="X-UA-Compatible" content="IE=edge">: Força o Internet Explorer a usar a versão mais recente do seu motor de renderização, evitando o "modo de compatibilidade" que quebra layouts modernos.
  3. <meta name="viewport" content="width=device-width, initial-scale=1">: A meta tag mais importante para a responsividade. Ela instrui o navegador a definir a largura da viewport igual à largura do dispositivo e a não aplicar zoom inicial.

4.1.2 Estrutura Completa do Template Básico:

<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="utf-8">
    <meta http-equiv="X-UA-Compatible" content="IE=edge">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <!-- As 3 meta tags acima *devem* vir primeiro no head -->
    <title>Bootstrap 101 Template</title>
    <link href="css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <h1>Hello, world!</h1>
    <script src="https://ajax.googleapis.com/ajax/libs/jquery/1.12.4/jquery.min.js"></script>
    <script src="js/bootstrap.min.js"></script>
</body>
</html>

4.2 A Filosofia Mobile First e o Viewport

O Bootstrap 3 foi projetado com a abordagem Mobile First: os estilos padrão são pensados primeiro para telas pequenas, e o layout se expande para telas maiores. Para que isso funcione, a meta tag viewport é indispensável. Sem ela, dispositivos móveis renderizam a página como se fosse uma tela de desktop, forçando o usuário a fazer zoom.

Opção de controle de zoom: É possível desabilitar o zoom adicionando user-scalable=no à meta tag viewport (ex: content="width=device-width, initial-scale=1, user-scalable=no"). Isso deve ser usado com cautela por questões de acessibilidade.

4.3 Integração de Arquivos CSS e JavaScript

O Bootstrap 3 depende de três arquivos principais:

  1. CSS do Bootstrap (bootstrap.min.css): Contém todos os estilos do framework. Deve ser incluído no <head>.
  2. jQuery (jquery.min.js): Biblioteca JavaScript necessária para os plugins do Bootstrap (modais, dropdowns, abas, etc.). Deve ser incluído antes do JS do Bootstrap, geralmente no final do <body> para não bloquear a renderização.
  3. JavaScript do Bootstrap (bootstrap.min.js): Contém os plugins de interatividade. Deve ser incluído após o jQuery.

Ordem de inclusão:

<!-- No <head> -->
<link href="css/bootstrap.min.css" rel="stylesheet">

<!-- No final do <body> -->
<script src="js/jquery.min.js"></script>
<script src="js/bootstrap.min.js"></script>

4.4 Compatibilidade com Navegadores Antigos (IE8)

O Bootstrap 3 usa elementos HTML5 (como <header>, <footer>, <nav>) e media queries CSS3, que não são nativamente suportados pelo Internet Explorer 8 e versões anteriores. Para garantir que o layout funcione nesses navegadores, o framework recomenda o uso de dois scripts de "polyfill":

  • HTML5 Shiv (html5shiv.min.js): Permite que o IE8 reconheça e estilize os novos elementos semânticos do HTML5.
  • Respond.js (respond.min.js): Adiciona suporte a media queries CSS3 no IE8, permitindo que o grid responsivo funcione.

Esses scripts são incluídos dentro de comentários condicionais para que sejam carregados apenas por versões antigas do IE:

<!--[if lt IE 9]>
  <script src="https://oss.maxcdn.com/libs/html5shiv/3.7.3/html5shiv.min.js"></script>
  <script src="https://oss.maxcdn.com/libs/respond/1.4.2/respond.min.js"></script>
<![endif]-->

Limitação importante: O Respond.js não funciona quando a página é aberta via protocolo file:// (ex: abrindo um arquivo HTML local). Para testar no IE8, é necessário acessar a página através de um servidor local (ex: http://localhost).

4.5 Instalação e Estrutura de Pastas

O processo de instalação do Bootstrap 3 é simples e manual:

  1. Download: Acesse getbootstrap.com e baixe a versão compilada do Bootstrap 3.
  2. Descompactar: Extraia o arquivo ZIP baixado.
  3. Copiar pastas: Copie as pastas css, fonts e js para dentro da pasta do seu projeto (ex: htdocs/seu-projeto/).

Estrutura de pastas do Bootstrap (versão compilada):

bootstrap/
├── css/
│   ├── bootstrap.css
│   ├── bootstrap.min.css
│   └── bootstrap.css.map
├── js/
│   ├── bootstrap.js
│   └── bootstrap.min.js
└── fonts/
    ├── glyphicons-halflings-regular.eot
    ├── glyphicons-halflings-regular.svg
    ├── glyphicons-halflings-regular.ttf
    └── glyphicons-halflings-regular.woff

Estrutura do projeto do desenvolvedor (exemplo em XAMPP/htdocs):

aprendendo-laravel/
└── public/
    ├── css/
    │   ├── bootstrap.min.css
    │   └── meucss.css
    ├── fonts/
    ├── imagens/
    ├── js/
    │   ├── jquery.min.js
    │   └── bootstrap.min.js
    ├── .htaccess
    ├── favicon.ico
    ├── index.php
    ├── robots.txt
    └── web.config
✅ Boa prática: Sempre separe seus arquivos dos arquivos do framework. Crie um arquivo CSS personalizado (como meucss.css ou style.css) para sobrescrever ou complementar os estilos do Bootstrap. Isso facilita futuras atualizações do framework.

4.6 jQuery: A Dependência dos Plugins

O Bootstrap 3 depende do jQuery para todos os seus plugins JavaScript. Sem o jQuery, funcionalidades como dropdowns, modais, tooltips, abas e carrosséis simplesmente não funcionarão. A versão recomendada é o jQuery 1.12.4 ou superior (dentro da linha 1.x), pois oferece suporte a navegadores antigos como o IE8.

Verificação de carregamento: É possível adicionar um fallback para garantir que o jQuery seja carregado:

<script src="https://ajax.googleapis.com/ajax/libs/jquery/1.12.4/jquery.min.js"></script>
<script>
  window.jQuery || document.write('<script src="js/jquery.min.js"><\/script>');
</script>

4.7 CSS Personalizado e Boas Práticas

O Bootstrap 3 fornece uma base sólida, mas cada projeto tem suas particularidades visuais. O arquivo meucss.css (ou style.css) é o local onde você deve adicionar:

  • Sobrescritas de estilos: Alterar cores, fontes ou espaçamentos padrão do Bootstrap.
  • Estilos para classes customizadas: Classes como .topo, .navegacao, .corpo, .menuEsquerdo, .conteudo, .rodape.
  • Ajustes de layout específicos: Pequenos ajustes que não são cobertos pelas classes utilitárias do framework.

Exemplo de meucss.css:

body {
    padding-top: 60px; /* Espaço para navbar fixa */
    font-family: 'Helvetica Neue', Helvetica, Arial, sans-serif;
}

.topo {
    background-color: #2c3e50;
    color: white;
    padding: 20px 0;
}

.rodape {
    background-color: #34495e;
    color: white;
    padding: 15px 0;
    text-align: center;
}
⚠️ Regra de ouro: Nunca modifique diretamente os arquivos bootstrap.min.css ou bootstrap.min.js. Se precisar de alterações, faça-as no seu arquivo CSS personalizado, para que o projeto possa ser atualizado sem perder suas customizações.

5. Integração com o Projeto e Componentes Finais

Chegamos ao momento de transformar todo o conhecimento teórico em um projeto real, colocando a mão na massa para montar a estrutura do seu site. Vamos explorar o passo a passo da integração do Bootstrap 3 em um ambiente de desenvolvimento local, a organização das pastas e a aplicação prática dos componentes HTML que construímos até aqui.

📥 Preparação do Ambiente e Download do Bootstrap

O primeiro passo para integrar o Bootstrap 3 em um projeto é preparar o ambiente de desenvolvimento. A abordagem mais comum para iniciantes é utilizar um servidor local como o XAMPP (ou WAMPP, LAMPP), que fornece o Apache para rodar seus arquivos PHP e o MySQL para banco de dados.

Com o servidor instalado, o processo de download do framework é simples:

  1. Acesse o site oficial do Bootstrap (getbootstrap.com) e baixe a versão compilada (v3.3.7 ou similar).
  2. Descompacte o arquivo ZIP baixado. Dentro dele, você encontrará a pasta bootstrap-3.3.7-dist, que contém as pastas css, js e fonts.
  3. O framework não inclui o jQuery. Você precisará baixá-lo separadamente do site oficial (jquery.com). Após baixar, crie um arquivo chamado jquery.js e coloque-o na pasta js do seu projeto.

📁 Estrutura de Pastas do Projeto

A organização dos arquivos é crucial para a manutenção do código. Dentro da pasta htdocs do seu XAMPP, crie uma pasta para o seu projeto (ex: aprendendo-laravel ou loja). A estrutura recomendada é separar os arquivos do framework dos seus arquivos personalizados:

htdocs/
└── seu-projeto/
    ├── css/
    │   ├── bootstrap.min.css  (framework)
    │   └── meucss.css         (seu estilo personalizado)
    ├── fonts/
    │   └── (arquivos do Glyphicons)
    ├── imagens/
    ├── js/
    │   ├── jquery.js
    │   └── bootstrap.min.js
    └── index.php

Essa separação permite que você atualize o Bootstrap no futuro sem perder as customizações do seu CSS.

🔗 Inclusão dos Arquivos CSS e JavaScript

Para que o Bootstrap funcione, você precisa incluir os arquivos corretos no seu HTML. A ordem de inclusão é fundamental:

  • No <head>: Inclua o CSS do Bootstrap antes de qualquer outro arquivo de estilo, para que suas regras personalizadas possam sobrescrevê-lo se necessário.
  • No final do <body>: Inclua o jQuery primeiro, e depois o JavaScript do Bootstrap. Isso garante que os plugins (como dropdowns e modais) encontrem a biblioteca jQuery já carregada.
<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="utf-8">
    <meta http-equiv="X-UA-Compatible" content="IE=edge">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Meu Projeto com Bootstrap</title>
    <!-- CSS do Bootstrap (primeiro) -->
    <link href="css/bootstrap.min.css" rel="stylesheet">
    <!-- CSS Personalizado (depois) -->
    <link href="css/meucss.css" rel="stylesheet">
</head>
<body>
    <h1>Hello, Bootstrap!</h1>

    <!-- jQuery (necessário para os plugins JS do Bootstrap) -->
    <script src="js/jquery.js"></script>
    <!-- JavaScript do Bootstrap -->
    <script src="js/bootstrap.min.js"></script>
</body>
</html>

🧱 Construção dos Componentes da View

Com a estrutura pronta, podemos montar a interface do projeto. O material apresenta uma "view" completa que integra o sistema de grid com os componentes que estudamos. Vamos construir essa estrutura passo a passo, usando as classes corretas.

Passo 1: Estrutura de Layout com Grid

A base do layout é um contêiner central (container) com uma linha (row) que divide a tela em três colunas: uma margem esquerda (col-md-2), o conteúdo principal (col-md-8) e uma margem direita (col-md-2).

<div class="container">
    <div class="row">
        <div id="margemEsquerda" class="col-md-2">
            <!-- Menu Lateral -->
        </div>
        <div id="conteudo" class="col-md-8">
            <!-- Conteúdo Principal -->
        </div>
        <div id="margemDireita" class="col-md-2">
            <!-- Barra Lateral Direita -->
        </div>
    </div>
</div>

Passo 2: Breadcrumbs (Rastro de Navegação)

Dentro da coluna de conteúdo, adicionamos o breadcrumb para indicar a localização do usuário. Lembre-se de que o item ativo não deve ter link.

<ol class="breadcrumb">
